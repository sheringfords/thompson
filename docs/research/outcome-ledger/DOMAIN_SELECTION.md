# Domain Selection (Phase 5)

Selection rules: multiple independent authorities genuinely required;
delayed/correctable outcomes; material non-token costs; stable job identity;
integration burden smaller than the semantic gap. Market size ignored.

## Outcome: no domain selected

- SUPPORT: killed (warehouse + native fields suffice).
- ITSM: killed (single system owns the episode).
- AP: killed (accounting already settles).
- SALES_OPS: killed (knowable facts covered; remainder is counterfactual).
- SOFTWARE_ENGINEERING: killed (closest call; incident-attribution heuristic
  binds any proposer equally; settlement rule is a view).

Per the mission rule (`if_none_pass`: stop implementation and issue
KILL_OUTCOME_LEDGER_DISCOVERY): **no executable assay is built**
(`go/assay/settlement/` stays absent — creating it would manufacture
evidence of demand the discovery refutes). Phases 6–8 executable work does
not run; their questions are answered analytically in ECONOMIC_RESULTS.md
and CORRECTION_AND_ATTRIBUTION.md from audit evidence. Phase 14 has no
subject.
