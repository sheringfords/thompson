# Cold Start and Data Asset (Phase 11)

Kill conditions tested analytically (no integrations built):

- Bespoke integrations before value: a ledger would need helpdesk +
  payments + provider + CRM/ERP/CI/incident feeds per domain before the
  first settled episode — heavier than the warehouse path it competes with.
- Compounding advantage: longitudinal outcome history compounds ONLY if the
  joined episode is uniquely valuable (killed in Phase 3). Archived traces
  alone are not a moat; a new entrant with the same warehouse access
  reproduces everything.
- Warehouse reconstruction: cheap in all five domains (stable IDs, event
  APIs, exportable usage). The supposed moat is stored traces.
- Minimum useful increments: none identified that are not ordinary ETL.

All four kill conditions hold. There is no data asset here beyond what the
customer's warehouse already accumulates. Day-one value via historical
import is the warehouse's value, not Thompson's.
